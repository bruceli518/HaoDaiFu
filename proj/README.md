# When BERT Meets Bilbo — reproducible implementation

This directory implements the paper's learning-curve protocol for Chinese disease classification.  For each stratified train/test split, it samples **10%–100%** of the available training documents from every class, fits each selected model, evaluates macro-F1, averages over repeated splits, and reports area under the learning curve (ALC).

## Layout

- `code/`: runnable implementation and dependencies.
- `figs/`: selected result slides exported from `过程数据/2020HealthNLP/2020HealthNLP.pptx`.
- `results/`: supplied experimental records, arranged by corpus and result type.  These are archival inputs, not outputs generated by the code.

## Quick start

```bash
cd code
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
python run_learning_curve.py --data ../example_data.csv --output-dir ../results/my_run --models bow bow_exp bert --repeats 10
```

Input must be a UTF-8 CSV with columns `text,label`.  The original patient narratives are not redistributed here: ChinaRe is proprietary and the included process files only contain aggregate experimental results.  Point `--data` to an authorized copy of either corpus.  The BERT model defaults to `bert-base-chinese` and downloads weights on first use.

The runnable comparison covers BOW, chi-square BOW expansion, and BERT, which are the central methods for the paper's conclusion. The archived curves retain CBOW, LSTM, and knowledge-graph variants; reproducing the original `*_KG` settings requires the CN-DBpedia/LINE embeddings, which are not among the supplied files.

The included result curves use these method columns, in order: `BOW`, `CBOW`, `CBOW_KG`, `BOW_EXP`, `BOW_EXP_KG`, `LSTM`, `LSTM_KG`, `BERT`.
